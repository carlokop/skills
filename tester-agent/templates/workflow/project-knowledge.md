# Project Knowledge

Replace this file with project-specific testing knowledge.

Examples:
- Laravel API tests live in `tests/Feature`.
- Unit tests live in `tests/Unit`.
- Frontend tests live in `next-app/tests`.
- Authentication uses Sanctum.
- Important roles are `admin`, `provider`, and `client`.
- Use factories for database test data.
- Do not call external services in tests.
- Prefer Docker test commands over host-machine commands.
